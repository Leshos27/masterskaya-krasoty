# «Мастерская красоты» — сайт салона красоты в Реутове

Чёрно-золотой сайт-визитка с онлайн-записью, обратным звонком, прайсом и журналом статей
в виде **винтажного перекидного календаря на кольцах**.

Готовый сайт лежит в папке **`public/`** — её и нужно загружать на хостинг.
Чтобы посмотреть локально, откройте `public/index.html` в браузере.

---

## Как редактировать

Всё содержимое — в папке `content/`. После любой правки запустите сборку:

```bash
python3 build.py
```

(Нужен только Python 3.8+, ничего устанавливать не надо.)

| Что поменять | Где |
|---|---|
| Телефон, адрес, часы работы, мессенджеры, домен | `content/site.json` |
| Услуги и цены (прайс-календарь и онлайн-запись обновятся сами) | `content/services.json` |
| Вопросы и ответы | `content/faq.json` |
| Статьи | `content/articles/*.md` |
| Дизайн | `public/assets/css/style.css` |
| Поведение (анимации, запись) | `public/assets/js/main.js` |
| Общая шапка/подвал/окна | `src/partials/*.html` |
| Главная, политика, 404 | `src/pages/*.html` |

### Как добавить статью

Создайте файл `content/articles/имя-статьи.md`:

```markdown
---
title: Заголовок статьи: подзаголовок
slug: imya-stati
date: 2026-11-15
category: Маникюр
category_id: manicure
description: Описание для поисковиков (до 160 символов), с упоминанием Реутова.
excerpt: Короткий анонс для листа календаря.
keywords: маникюр Реутов, ...
---

Текст. **Жирный**, [ссылка](girudoterapiya.html).

## Подзаголовок

- пункт списка

> Важное замечание (рамка).
```

`category_id` — одно из: `hair`, `manicure`, `pedicure`, `massage`, `hirudo`, `hijama`, `cosmetology`
(от него зависит, какая услуга будет выбрана в кнопке «Записаться» под статьёй).
Новая статья автоматически появится в календаре на главной, в журнале и в sitemap.

## Онлайн-запись через ClickTak (рекомендуется)

Запись можно вести в **ClickTak**: клиент видит реальные свободные окна мастеров, запись сразу попадает
в журнал администратора, клиенту приходят подтверждение и напоминания в Telegram.

1. Запустите ClickTak на сервере и заведите в нём салон: услуги, мастера, график.
   В «Настройках» поставьте фирменный цвет `#c9a45c` (золотой, как на сайте).
2. В `content/site.json`, блок `clicktak`:
   - `url` — адрес ClickTak, например `https://clicktak.ru`;
   - `business` — короткое имя салона в ClickTak (из адреса страницы записи `/b/<имя>`);
   - `services` — по желанию: номер услуги ClickTak для каждого раздела. Тогда кнопка «Записаться»
     у раздела сразу откроет эту услугу. Номер виден в адресе после `service=`, если нажать на услугу
     на странице записи салона в ClickTak. `null` — клиент выберет услугу сам.
3. Запустите `python3 build.py` и опубликуйте сайт.

Что меняется на сайте: секция «Онлайн-запись» показывает окно записи ClickTak в тёмной теме,
а все кнопки «Записаться» (шапка, нижняя панель на телефоне, разделы услуг, прайс, статьи)
открывают его поверх страницы. Пока `url` пустой, работает встроенная форма сайта (см. ниже).

Обратный звонок по-прежнему идёт через `api/send.php`.

## Как включить приём заявок (встроенная форма)

Сейчас включён **демо-режим** (`"demo": true` в `content/site.json`): формы работают,
но заявки никуда не уходят. Чтобы заявки приходили администратору:

1. Создайте Telegram-бота у [@BotFather](https://t.me/BotFather), добавьте его в чат администраторов.
2. Скопируйте `public/api/config.example.php` → `public/api/config.php` и впишите токен бота и chat_id
   (можно добавить e-mail для копии).
3. В `content/site.json` поставьте `"demo": false` и запустите `python3 build.py`.
4. Загрузите `public/` на хостинг с PHP (Beget, Timeweb, REG.RU и т. п.).

Обработчик `api/send.php` проверяет телефон, отсекает ботов (скрытое поле), ограничивает частоту заявок
и ведёт резервный журнал `leads.log` (вне публичной папки).

Альтернатива: если салон пользуется YCLIENTS / DIKIDI — можно поставить их виджет вместо формы записи.

- [ ] **Ссылки на Telegram / WhatsApp / VK**
- [ ] **Цены** — ориентировочные, проверьте все позиции в `content/services.json`
- [ ] **Политика конфиденциальности** — реквизиты в `[квадратных скобках]` в `src/pages/privacy.html`
- [ ] Фотографии салона и мастеров (сейчас дизайн построен на графике — реальные фото повысят доверие)

## Важно по закону

- **Гирудотерапия** (и, как правило, хиджама) — медицинские услуги: для них нужна медицинская лицензия
  и специалист с медицинским образованием. Рекламировать их без лицензии нельзя.
- Пометка «Имеются противопоказания. Необходима консультация специалиста» обязательна для рекламы
  медицинских услуг (ст. 24 закона «О рекламе») — она уже стоит на сайте.
- Формы собирают персональные данные — нужны согласие (галочка уже есть) и политика по 152-ФЗ.

## Продвижение (SEO и карты)

1. Добавьте сайт в **Яндекс.Вебмастер** и **Google Search Console**, отправьте `sitemap.xml`.
2. Заведите/обновите карточки в **Яндекс.Бизнесе**, **2ГИС** и **Google Business** с тем же адресом,
   телефоном и часами, что на сайте (одинаковые данные везде — важно для геопоиска).
3. Просите довольных клиентов оставлять отзывы на картах.
4. Пишите статьи регулярно (1–2 в месяц) — по реальным вопросам клиентов, с упоминанием Реутова.
